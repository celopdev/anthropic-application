## Install

### Claude Desktop

1. Open the sidebar and click **Customize**
2. Go to **Browse plugins**
3. Click **Add marketplace from GitHub**
4. Enter: `celopdev/anthropic-application`
5. Install the **celestin** plugin

That's it.

### Claude Code

Make sure you have [Claude Code](https://claude.ai/code) installed, then:

```
/plugin marketplace add celopdev/anthropic-application
/plugin install celestin@celestin-prudhomme
```
